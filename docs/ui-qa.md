# 界面更新验证清单

- 模式：自由分析隐藏目标、练习参数、成绩、练习记录、下一题、目标图例与调应用按钮；保持选音、MIDI、节拍器、候选与五度圈可用。三和弦与进行只显示各自参数。往返切换保留配置与折叠偏好。
- 键盘：白键固定为 128 px，小窗口为 104 px；密集音集与长和弦名称不改变键盘和面板高度。音程不重叠，横向滚动仍可用。
- 配色：设置中的五个色板均可选择，主界面、五度圈、琴键、弹窗、极简窗口、原生标题栏同步。切换后重载保留选择，旧记录默认 Live 黑。
- 回归：默认静音，练习判定、踏板、暂停与导出、左右侧栏、折叠、极简模式与置顶。
- 探索：无效配色配置回退；练习中换肤不重置计分或音符；自由分析折叠后切回练习；最小窗口密集音集。
- 视觉证据：五套配色 × 三种模式 × 常用/最小窗口；设置色板；极简窗口；可见面板边界、文字与音程标签无裁切。

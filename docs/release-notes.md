# 和弦镜 · 练琴 v1.2.1

本次更新缩小极简模式窗口，方便练琴时贴边放置。

- 极简模式默认由 480×280 缩至 320×200，最小由 380×260 缩至 280×180。
- 收紧标题栏、和弦名与组成音排版，保留低音、MIDI 状态、置顶和返回完整界面。
- 长和弦名自动适配；密集组成音可横向查看，窗口尺寸保持固定。
- 保留上次调整的极简尺寸，退出后恢复完整窗口尺寸与最大化状态。
- 分发版继续内置 Akai Steinway，每次启动默认静音。

完整解压 `ChordLens-Practice-v1.2.1-windows-x64.zip` 后运行 `和弦镜练琴版.exe`，保留整个文件夹。
当前版本未做代码签名。提供 SHA-256 校验文件。

本次验证覆盖原生极简窗口默认及最小尺寸、长和弦名、密集音集、MIDI 与延音、置顶、页面重载、尺寸记忆、完整窗口恢复、最大化与默认静音。既有完整验证范围见 `docs/validation.md`。不同实体键盘和驱动仍需实机验证。

# 和弦镜 · 练琴 v1.1.0

本次更新精简模式界面，缩短琴键，并加入五套配色。

- 设置内新增 Live 黑、Live 白、FL Studio、Cubase、Medly 配色，记住上次选择。
- 五度圈、琴键、弹窗、原生标题栏和极简窗口同步换肤；换肤保留当前音符和练习进度。
- 自由分析隐藏练习参数、成绩、记录、下一题与目标提示，保留分析、MIDI、节拍器和输入工具。
- 和弦练习与和弦进行只显示各自参数，暂不可用的试听、跳过和调性应用按钮自动隐藏。
- 琴键固定为 128 px，小窗口为 104 px；密集音集、长名称与按钮显隐不引起面板上下伸缩。
- 默认静音。现有记录与折叠偏好可继续使用，旧配置默认 Live 黑。

完整解压 `ChordLens-Practice-v1.1.0-windows-x64.zip` 后运行 `和弦镜练琴版.exe`，保留整个文件夹。
当前版本未做代码签名。提供 SHA-256 校验文件。

验证：16 项逻辑测试与 6,252 组和弦组合；五套配色 × 三种模式 × 四种窗口尺寸；浏览器与原生桌面检查；练习、音频、导出、折叠与极简窗口回归；10,000 条控制消息压力检查。不同实体键盘和驱动仍需实机验证。

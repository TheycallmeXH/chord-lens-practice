# 和弦镜 · 练琴 v1.0.1

首个公开 Windows x64 桌面发行版。

- MIDI 实时和弦分析、候选名称、组成音、转位、力度与定性听感。
- 三和弦、七和弦、转位、12 调与和弦进行练习，支持踏板、保持判定与记录导出。
- 深色工作界面、键盘音程关系、五度圈、面板折叠、侧栏边缘开关与极简窗口。
- 自由分析隐藏练习目标区，当前和弦使用完整宽度，面板高度稳定。
- 减少空闲刷新与重复 MIDI 分析，修复损坏记录及设备重连中的异常处理。
- 默认静音，记录与 MIDI 数据保存在本机。公开包包含可分发的 Jost 字体。

完整解压 `ChordLens-Practice-v1.0.1-windows-x64.zip` 后运行 `和弦镜练琴版.exe`，保留整个文件夹。
当前版本未做代码签名。提供 SHA-256 校验文件。

验证：16 项逻辑测试与 6,252 组和弦组合；四种窗口尺寸；原生练习、音频、导出与极简窗口回归；10,000 条控制消息压力检查。不同实体键盘和驱动仍需实机验证。

# 和弦镜 · 练琴 v1.2.0

本次更新加入 SF2 采样钢琴，分发版默认挂载 Akai Steinway。

- 内置 `akai_steinway.sf2`，默认 bank 0 / program 0 `piano1`，钢琴发声使用真实采样。
- 支持 MIDI 力度、重复落键、踏板延音与 A4 参考音调音；目标试听与实时弹奏使用独立通道。
- 设置内新增 SF2 选择按钮，记住本机选择。更换音色保留当前 MIDI 音符和练习进度。
- 每次启动仍默认静音，首次开启时加载音色，之后复用；总静音停止尾音并暂停采样处理。
- 音频合成运行在 AudioWorklet 线程，限制复音数和解码采样缓存。
- 公开包包含 Akai 音色，Equinox Grand Pianos 自用音色不包含在公开包中。

完整解压 `ChordLens-Practice-v1.2.0-windows-x64.zip` 后运行 `和弦镜练琴版.exe`，保留整个文件夹。
当前版本未做代码签名。提供 SHA-256 校验文件。

验证：16 项逻辑测试与 6,252 组和弦组合；五套配色 × 三种模式 × 四种窗口尺寸；浏览器与原生桌面检查；练习、音频、导出、折叠与极简窗口回归；SF2 采样输出、力度、延音、换库与静音检查；10,000 条控制消息压力检查。不同实体键盘和驱动仍需实机验证。

# 和弦镜 · 练琴 1.0.0 正式版

本次按作者指定版本号发布为 1.0.0，包含此前练琴版的累计改进；历史版本保留。

- 修复置顶按钮切换后窗口失去前台、被其他窗口遮住的问题，覆盖完整与极简窗口。
- 和弦练习细分为 5 级、15 类、32 种，可选择单一和弦、混合练习与转位。
- 超时后高亮目标琴键；提示等待时间、根音音区可设置，暂停不计入等待。
- 和弦进行扩至 18 套，包含流行、小调、爵士、调式与蓝调，支持移调、就近转位和保留共同音衔接。
- 支持导入标准 MIDI 文件，选择音轨、调整起音窗或拍长分组、预览后生成练习；保留实际组成音与原音区。
- 声音与 MIDI 试听默认开启。分发版内置 Akai Steinway SF2，支持更换音色、力度、踏板、调音与目标试听。
- 设置采用分类导航；规则说明重新排版；关于面板显示版本、作者 Katuria、项目仓库与授权文本。
- 新增原创深灰与白色应用图标，同步程序文件、任务栏与应用内标识。
- 保留五套配色、五度圈、面板折叠、边缘侧栏开关、320×200 极简窗口、MIDI 自动连接与超时恢复。

MIDI 导入用于和弦音组练习，不包含旋律自动配和声或节奏评分；文件在本机解析，重启后需重新导入。真实设备端口已单独检查，跨品牌驱动与长期实弹仍需各自验证。

完整解压 `ChordLens-Practice-v1.0.0-windows-x64.zip` 后运行 `和弦镜练琴版.exe`，保留整个文件夹。当前版本未做代码签名。提供 SHA-256 校验文件。

项目代码与原创图标采用 MIT；字体、引擎与音色库遵循各自授权。公开包不含 Ableton 字体或仅限本地自用的 Equinox 音色库。

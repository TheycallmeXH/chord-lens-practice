# 和弦镜练琴版

完整解压后双击 `和弦镜练琴版.exe`，移动时保留整个应用文件夹。
Windows x64；无需安装 Node.js 或启动网页服务器。当前版本未做代码签名。

接入 MIDI 键盘后自动接收。声音每次启动默认关闭；外接 MIDI 的合成试听需在设置中单独开启。
节拍器可以无声闪拍。

自由分析显示当前和弦、候选、组成音、音程与定性听感。
各模式只显示当前可用功能，自由分析隐藏练习参数、成绩和目标提示。
和弦练习包含大小三和弦、七和弦、转位、12 调；和弦进行支持移调。
正确音集默认保持 350 ms，全部松键后进入下一题；若计入踏板，也需松开踏板。
任意八度允许八度重复，指定音区严格匹配实际音高；转位检查实际低音。
整组松键仍未正确，记一次重试。清音不记错误，暂停不计时。

空格开始 / 暂停，Escape 清音。A W S E D F T G Y H U J K 对应 C4–C5。
点击屏幕琴键也可输入；开启“保持选音”后再次点击松开。

五度圈外圈为大调，内圈为关系小调；轮廓标目标根音，填色标当前根音。
点击调名浏览调号，回车箭头将所选大调用于下一轮练习。
键盘上方可显示相邻音程或相对低音的音程。

面板标题箭头折叠面板，左右边缘箭头隐藏侧栏，顶部按钮恢复布局。
极简模式只显示和弦名、组成音、低音与 MIDI 状态；进入时暂停练习，返回后手动继续。
折叠、隐藏或极简模式都不影响 MIDI 接收。

设置中的“配色”可切换 Live 黑、Live 白、FL Studio、Cubase、Medly。
换肤立即生效，标题栏与极简窗口同步，并记住上次选择。
琴键高度固定，小窗口会进一步缩短，音程关系保留在键盘上方。

练习记录只保存在本机 Windows 用户的应用数据目录，保留最近 100 轮，可导出 JSON。
同一音集可能存在多个合理和弦名称；情绪仅作定性听感参考。
字体使用可分发的 Jost，若本机已有 Ableton Sans 则优先使用；中文由系统字体回退。

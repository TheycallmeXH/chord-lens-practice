# 和弦镜练琴版

完整解压后双击 `和弦镜练琴版.exe`，移动时保留整个应用文件夹。
Windows x64；无需安装 Node.js 或启动网页服务器。当前版本未做代码签名。

接入 MIDI 键盘后自动接收。声音与外接 MIDI 试听每次启动默认开启，可分别关闭。
节拍器可以无声闪拍。
内置 Akai Steinway SF2，默认选用 piano1；启动时加载真实钢琴采样。
设置中的文件夹按钮可更换 SF2，选择会保存在本机。目标试听与实时弹奏共用所选音色。

自由分析显示当前和弦、候选、组成音、音程与定性听感。
各模式只显示当前可用功能，自由分析隐藏练习参数、成绩和目标提示。
和弦练习分 5 级、15 类、32 种和弦：三和弦、挂留、六和弦、加九、七和弦、九 / 十一 / 十三及变化和弦。
每级可选类别、单一和弦或混合练习，支持 12 调。设置中可选择原位、第一 / 第二或全部转位；三和弦转位类别自带轮换。
扩展和弦采用 Tonal 字典音集：属十一省略三音，十三省略十一音。
和弦进行提供 18 套模板，覆盖流行、小调、爵士、调式与布鲁斯，可移调并选就近转位。
正确音集默认保持 350 ms。和弦练习全部松键后切题；和弦进行默认允许保留共同音，也可设为全部松键。
若计入踏板，仍踩住的音也参与判定。同一组持续按住的音不会重复计分。
本轮完成后可重练相同序列；和弦练习的刷新按钮重新出题。
任意八度允许八度重复，指定音区严格匹配实际音高；转位检查实际低音。
整组松键仍未正确，记一次重试。清音不记错误，暂停不计时。
超时提示默认等待 8 秒，再显示目标组成音并高亮实际琴键。设置中可设 0–120 秒、C2–B5 根音音区。
提示计时不包含暂停，重试保留计时，进入下一题重新计时。提示音区同时决定“指定音区”的目标音高。

和弦进行可导入标准 MIDI 文件（Format 0 / 1，每拍 ticks，最大 16 MB）。
选取和声音轨，按起音时间窗或拍长提取，预览确认后开始练习。鼓、单音和双音组会跳过。
无法确定名称的组合显示为“音集”，仍按组成音判定；目标保留原文件音区。
导入不包含旋律自动配和声、踏板还原或节奏评分；重启后需要重新导入。

空格开始 / 暂停，Escape 清音。A W S E D F T G Y H U J K 对应 C4–C5。
点击屏幕琴键也可输入；开启“保持选音”后再次点击松开。

五度圈外圈为大调，内圈为关系小调；轮廓标目标根音，填色标当前根音。
点击调名浏览调号，回车箭头将所选大调用于下一轮练习。
键盘上方可显示相邻音程或相对低音的音程。

面板标题箭头折叠面板，左右边缘箭头隐藏侧栏，顶部按钮恢复布局。
极简模式只显示和弦名、组成音、低音与 MIDI 状态；进入时暂停练习，返回后手动继续。
折叠、隐藏或极简模式都不影响 MIDI 接收。

设置采用左侧分类，可在“界面与配色”切换 Live 黑、Live 白、FL Studio、Cubase、Medly。
换肤立即生效，标题栏与极简窗口同步，并记住上次选择。
“自定义”可调背景、面板、文字、强调色与琴键颜色；支持命名保存、修改、复制和删除，最多 24 套。
调色即时预览，保存后生效；关闭设置时还原未保存的调色。
钢琴在空闲时暂停音频处理，下次按键或试听时自动恢复，已加载音色继续复用。
“关于”显示版本、作者 Katuria、仓库地址及完整授权文本。
琴键高度固定，小窗口会进一步缩短，音程关系保留在键盘上方。

练习记录只保存在本机 Windows 用户的应用数据目录，保留最近 100 轮，可导出 JSON。
同一音集可能存在多个合理和弦名称；情绪仅作定性听感参考。
字体使用可分发的 Jost，若本机已有 Ableton Sans 则优先使用；中文由系统字体回退。

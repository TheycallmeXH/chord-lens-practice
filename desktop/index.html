练习与识别规则

练习判定

任意八度
比较音名，允许八度重复；转位题同时检查最低音。
指定音区
逐个匹配目标实际音高。提示音区指定原位根音八度，转位保留音序。
正确保持
音符补齐后默认保持 350 ms。部分音先落下可继续补齐；未正确便整组松键，计一次重试。
和弦衔接
和弦进行默认允许保留共同音；正确后改变按键即可进入下一题。同组按键一直保持，不会重复计分。可在设置改为全部松键；踏板音计入时也需释放。

内容与提示

五级难度支持按类别、单一和弦或本级混合练习。扩展和弦采用 Tonal 字典音集：属十一省略三音，十三省略十一音。就近转位尽量减少相邻目标的声部移动。

超时提示默认等待 8 秒；暂停不计时，重试不重置，换题重新计时。完成后可重练同一轮，或用序列旁的换组按钮生成新题。

导入 MIDI

支持标准 MIDI Format 0 / 1，可选择伴奏音轨。“同时起音”合并指定毫秒内的新按键；按拍聚合适合分解和弦。鼓通道 10、单音及双音组会跳过，相邻重复配置会合并。

导入保留原文件音区，预览确认后逐组练习。无法确定和弦名时显示“音集”，判定仍按实际组成音进行。文件在本机解析，不会上传；当前轮按音集判定，不作节奏评分。

识别边界

同一音集可能有多个合理名称；省略音、无根音配置属于推测。练习判定直接比较音高，不受候选命名影响。和弦情绪仅作定性听感参考。

落键差是当前按住音符的首次触发时间差，力度差是最大与最小 MIDI 力度之差；两者不等于节奏评分。

输入与声音
